# Download Samples

Clone the free React Native samples from [WebRTC-React-Native-SDK](https://github.com/ant-media/WebRTC-React-Native-SDK).

```bash
git clone https://github.com/ant-media/WebRTC-React-Native-SDK.git
cd WebRTC-React-Native-SDK
```

Sample implementations live under `example/src/` (Publish, Play, Peer, Conference, Chat).

## Install dependencies

Use **either** npm or yarn for the whole project — do not mix them.

### npm

```bash
npm install
cd example
npm install
npm run android
```

### yarn

```bash
yarn install
cd example
yarn install
yarn android
```

## Run the project

After a successful build, the sample app launches on your connected device or emulator.
