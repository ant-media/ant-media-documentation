# Create Android Project

Create a minimal Android app in Android Studio before adding the SDK dependency.

## Step 1: Open Android Studio

Launch Android Studio and click **Create New Project**.

![](@site/static/img/sdk-integration/android-sdk/android-new-project-page.png)

## Step 2: Select project template

Choose **No Activity** and click **Next**.

![](@site/static/img/sdk-integration/android-sdk/android-project-naming-screen.png)

## Step 3: Name the application

Enter a name (for example `MyWebRTCStreamingApp`) and click **Finish**.

Next: [Add the SDK dependency](/guides/developer-sdk-and-api/sdk-integration/android-sdk/android-dependency/).
