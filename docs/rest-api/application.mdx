# Application REST API

Application-level REST APIs manage broadcasts, VoD assets, stream sources, and related operations.

**Base URL:** `https://your-server:5443/{application}/rest/v2`

For authentication and getting started, see the [REST API guide](/guides/developer-sdk-and-api/rest-api-guide/). You can also try these APIs interactively at [antmedia.io/rest](https://antmedia.io/rest/).
