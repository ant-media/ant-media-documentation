# Management REST API

Management Panel REST APIs cover server-level operations such as creating applications, managing users, and reading system resources.

**Base URL:** `https://your-server:5443/rest/v2`

These endpoints require Management authentication (JWT via `ProxyAuthorization` or username/password). See the [Management REST API guide](/guides/developer-sdk-and-api/rest-api-guide/management-rest-apis/). You can also browse this API on [antmedia.io/rest](https://antmedia.io/rest/).
